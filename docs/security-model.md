# 安全与策略边界

这是同一 OS 用户下的人机协作工具，不是恶意代码隔离沙箱。
有同一用户文件访问权的程序可以改配置或直接运行原生客户端；请用真实数据库账号权限、sudoers 和独立运行用户做隔离。

## SSH

Web 保存 `allow` / `ask` / `deny` 的 sudo 策略。命令中提权关键词匹配采用保守规则，可能误报只读命令。
`ask` 创建人工审批，批准后相同命令可消费指定次数；过期不可用。rc=5 为拒绝，rc=6 为待审批。
无 policy.json 时保持旧 CLI 行为，不默认阻止提权；管理员应显式保存限制。

受管理执行的批准绑定连接/凭据版本、目标身份和策略版本。执行占用不随审批 TTL 自动解除，避免慢命令重复执行；
进程异常退出留下的占用需人工核查，不能靠重新审批绕过。审批锁失效时拒绝决定或消费。
sudo 密码通过本机 OS keychain 代输，缓存/NOPASSWD 时不发送；已知执行前失败释放占用，未知状态消耗批准且不自动重放。
普通用户允许列表只豁免经 UID 确认的非敏感身份和简单命令，操作系统授权始终生效。

## 数据库

最大等级为 `read` / `write` / `ddl`，库、表、PG schema 可以配置白名单。
未设置（null）表示不限。PG 库白名单不等于 schema 隔离，需另外设置 allowed_schemas。
SQL 目标识别是启发式；无法解析的表目标可能按兼容约定放行并记 warning，不能据此隔离恶意 SQL。
视图、函数、触发器及服务端代码的隐含行为也应由数据库权限限制。

原 dbbind 只读守卫继续有效。即使用户给 --write/--unsafe，也不能越过配置的最大等级。
export 同样检查。临时 --database 按实际库校验。审批 target 包含引擎、实际默认库和原 SQL，
同别名切换库不能复用批准。升级前不含数据库上下文的旧审批需重新申请。

策略存在但模块缺失、策略损坏或需要审批却无法持久化时拒绝。缺少策略且未安装模块时保持兼容。
禁止把拒绝当成 bug 绕过，也不能自行编辑审批单。

## Web / 凭据

默认回环监听；显式 LAN 绑定支持本机私有地址与 0.0.0.0，首次设密码需终端一次性 token。
HTTP 不加密，可信网络临时导入后关闭。Web 不支持公网部署、多用户 RBAC 或内置 TLS。
管理密码用 PBKDF2 存哈希；会话 Cookie 为 HttpOnly，写 API 验证 CSRF，登出吊销现有会话。
两个控制台共享管理凭据，任一登出会使两边旧会话失效。

用户数据库密码可能以明文存在本地配置，推荐环境变量引用并限制文件权限。
API 不回显保存的密码/私钥。凭据传递避开 argv；审计尽量脱敏常见凭据形式，但用户不应在命令或 SQL 中嵌入口令。
审计包含命令/SQL 目标（截断），也属于应妥善保护的本地数据。

新增 sudo 密码和 AI API key 仅通过成熟的系统 keyring 后端保存，本机配置仅存随机引用；后端不可用时明确失败，禁止明文降级。
登录密码/私钥替换先验证连接；清除 sudo 密码会删除对应钥匙串项。Xshell 解锁仅使用本人提供的主密码/源身份，5.1+ 验证摘要；未知版本不猜测，不执行导入命令或读取引用密钥路径。
导入预览秘密只留在有期限的本机内存；确认后登录密码和未解锁密文仅进系统钥匙串。暂不可达连接必须经额外明确确认才能登记为待验证，不能伪装成已连接或可供 agent 使用。
只有已认证且通过 CSRF 的导入预览可接受 24 MiB JSON（源文件总量16 MiB），其他接口保留 1 MiB 上限。旧版本无摘要密码格式不能验证完整性，解密不等于服务器认证。
审计分页索引和 AI 队列均为私有运行时数据，不进入发行包。

## AI 审批

默认关闭，需本人配置精确别名范围。审核进程独立于执行 agent 的对话，模型没有执行工具，决策严格校验且仅使用一次。
硬拒绝、SQL 上限、白名单、写入参数和安全配置操作不能由 AI 覆盖；模型超时/异常、人工已处理或配置/目标变化时回退人工。
只发送脱敏的当前命令/SQL和必要目标信息；脱敏不是通用数据分类器，仍应避免把秘密嵌入命令/SQL。
后台 queue 是有界并可过期的，取消与停止会使晚结果失效。独立模型仍可能误判，配置范围须符合可接受的实际账号权限。

## 安装与更新

一键安装使用 GitHub HTTPS 和发行包 SHA-256；没有独立签名信任链。
安装只替换代码，不触碰连接、密钥、管理密码、policy、approvals 或审计。
用户自写或修改过的 agent 指引不覆盖；安装器管理且校验未变化的指引随版本更新。旧代码备份留在原文件旁；卸载仅删除未被用户修改的已安装文件。
