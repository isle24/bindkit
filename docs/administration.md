# 管理功能与验收边界

## 凭据和身份

服务器「编辑」中的登录密码仅用于重新建立公钥访问。修改密码或私钥前会验证替代连接，成功后才提交本机记录。
别名、策略和旧密钥保留。旧远端公钥是否吊销由本人单独决定，系统不会自动删除。

sudo 认证单独配置为「不保存」「系统钥匙串」或「服务器 NOPASSWD」。本机状态只保存随机引用；密码由
`keyring` 交给操作系统后端保存。没有可用后端时无法保存密码。Linux 纯终端/NAS 环境未必运行钥匙串服务，
因此推荐在运行 BindKit 的本机配置，而不是在远端 NAS 中保存。

`sshbind exec --json --as-user USER alias 'command'` 把目标身份纳入审批。普通用户须由远端 UID 解析确认并位于
该服务器允许列表内；系统身份、UID 0、未知身份、嵌套/动态命令不会获得豁免。允许列表不是 sudoers 替代品。

受管理执行在远端 sudo 认证后发出随机开始标记，之后才发送命令输入。命令输入不会被当成 sudo 密码；
缓存/NOPASSWD 时不会读取钥匙串。执行前明确认证失败会释放单次批准的占用，执行已开始或状态未知会消耗批准。
连接中断、超时和无法判断执行状态时禁止自动重放。TTY/MFA、交互式 shell 和复杂旧式 sudo/su 写法可能需要
改用显式 `--as-user` 或人工处理，错误会说明限制。

## 独立 AI 审批

1. 执行 `bash install.sh --with-integrations` 安装隔离运行时，启动任一控制台。
2. AI 设置填写兼容 API 地址、模型及仅写入 API key；先测试连接。模型发现不可用时可直接填写模型名。
3. 从当前工具的别名列表选择审核范围，其他工具的范围保留。选择「仅建议」或「自动审批」并保存。
4. 请求仍先经过确定性策略与原有写入守卫。只有允许进入审批的请求才会排队审核，硬拒绝与受保护操作不会交给 AI。
5. 审核进程仅接收脱敏的当前请求，不持有执行工具。输出须为严格的 approve/reject/human JSON；任意错误回到人工。
6. 写入决定前再次检查配置、策略、请求指纹和人工状态，使用原审批锁原子处理。批准仅一次、有效期 60–300 秒。

CLI 等待有时间上限。超时会取消本次审核，晚返回不能自动批准；原请求继续显示在人工审批页。
网页关闭不影响已启动的审核进程。关闭 AI 模式会停用审核并取消排队任务；正在进行的模型调用结束后进程退出。
模型输出的自由文本理由不写入审计，避免反射命令中的秘密。审计保留实际决定者 `ai`/`web`。

这是一层协作守卫，本机同一用户仍可编辑源代码/策略；需要强隔离时使用独立操作系统和数据库账号。

## 会话导入

控制台先解析文件到内存预览，10 分钟过期，最多保留 16 个预览；不存储原始上传文件。
每批最多 64 个文件、700 KiB。支持 Xshell `.xsh`/普通 ZIP、FinalShell SSH JSON 与 OpenSSH config。
Xshell `.xts` 只有实际为普通 ZIP 时可读取；受保护容器请导出单独 `.xsh`。厂商加密密码不恢复。

只读取 SSH 地址、端口、用户名、会话名与私钥文件名提示。不会读取引用的私钥路径、跟随 Include、执行
ProxyCommand/LocalCommand，也不会把上传文件中的密码传入创建接口。确认时本人补充密码/私钥；每行反馈成功或失败。
导出文件未指定用户名时必须明确填写，不会静默默认成 root。控制台只有在公钥安装并验证登录后才登记新别名。
失败条目可修正后重试；成功条目不能重复提交。已有别名不覆盖，可更换导入别名。

## 分页审计

`GET /api/audit?page=1&page_size=50&tool=all&actor=ai&decision=approve&alias=demo` 返回
`entries,total,page,page_size,pages,has_next,has_prev,snapshot`。后续页带同一 `snapshot`，新增事件保持在快照之外。
日志轮换/截断使快照失效，返回 HTTP 409。旧 `limit` 调用仍兼容。

运行时 SQLite 索引只保留日志偏移与过滤元数据，权限 0600；响应和索引构建均有内存上限。
损坏行、超大行与未完成尾行不当作有效事件。索引可重建，不是第二份审计正文。

## 验收范围

自动测试仅使用临时 HOME、合成凭据、假 SSH 与模型、临时 SQLite 和本地浏览器。
真实 NAS 的 sudoers、PAM、TTY、多因素和钥匙串解锁行为必须在本人配置完成后单独验收。
不要把隔离测试通过写成真实服务器已验证。
